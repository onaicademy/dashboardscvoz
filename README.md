# ShowToday AI Analytics - MVP Frontend

Веб-платформа для анализа текстовых переписок отдела продаж с использованием ИИ.

## 🚀 Быстрый запуск

### 1. Установка зависимостей

```bash
cd "/Users/miso/Downloads/Проект Show Today/showtoday-ai-analytics"
npm install
```

### 2. Запуск dev-сервера

```bash
npm run dev
```

Приложение откроется на `http://localhost:3000`

### 3. Сборка для продакшена

```bash
npm run build
npm run preview
```

## ✨ Основные возможности

### Реализовано:

- ✅ **Dashboard** - сводная аналитика с метриками
- ✅ **Анализы чатов** - список проанализированных диалогов
- ✅ **Детальный просмотр** - полный анализ чата с заключением ИИ
- ✅ **Маркетинг** - источники лидов, ROI, рекомендации ИИ
- ✅ **Тренды** - графики динамики показателей
- ✅ **Настройки** - управление темой и языком
- ✅ **Темная/Светлая тема** - переключатель в Header
- ✅ **Локализация RU/KZ** - переключатель языка
- ✅ **Адаптивный дизайн** - работает на всех устройствах
- ✅ **Объемный логотип 8D** - SVG с тенями и градиентами

## 📊 Структура проекта

```
showtoday-ai-analytics/
├── components/
│   ├── Header.tsx          # Шапка с переключателями
│   ├── Sidebar.tsx         # Боковое меню
│   └── Logo8D.tsx          # Логотип 8D (SVG)
├── pages/
│   ├── Dashboard.tsx       # Главная панель
│   ├── Analytics.tsx       # Список анализов
│   ├── ChatDetail.tsx      # Детальный просмотр
│   ├── Marketing.tsx       # Маркетинг-аналитика
│   ├── Trends.tsx          # Графики трендов
│   └── Settings.tsx        # Настройки
├── contexts/
│   ├── ThemeContext.tsx    # Управление темой
│   └── LanguageContext.tsx # Локализация
├── services/
│   └── mockData.ts         # Тестовые данные
├── types.ts                # TypeScript типы
└── App.tsx                 # Главный компонент
```

## 🎨 Дизайн

**Цвета бренда:**
- Желтый: `#FFD700` (основной)
- Черный: `#1A1A1A` (темный сайдбар)
- Светлый фон: `#F8FAFC`
- Темный фон: `#0F0F0F`

**Шрифт:** Inter (Google Fonts)

**UI библиотеки:**
- Lucide React - иконки
- Recharts - графики
- Framer Motion - анимации
- Tailwind CSS - стилизация

## 🌍 Локализация

Переключатель **RU/KZ** в правом верхнем углу Header.

Переводы находятся в `contexts/LanguageContext.tsx`.

## 🌓 Темная тема

Переключатель **темы** (иконка солнца/луны) в Header.

Настройки сохраняются в localStorage.

## 📱 Адаптивность

- **Desktop**: полный интерфейс с сайдбаром
- **Tablet**: сайдбар скрывается, открывается бургером
- **Mobile**: оптимизированные карточки и таблицы

## 🔧 Технологии

- **Framework**: Vite + React 19
- **Язык**: TypeScript 5.8
- **Стили**: Tailwind CSS 4 (через CDN)
- **Роутинг**: React Router 7
- **Графики**: Recharts 3.7
- **Анимации**: Framer Motion 12
- **Иконки**: Lucide React

## 📦 Зависимости

Все зависимости загружаются через ESM CDN (esm.sh), поэтому:
- ✅ Нет node_modules
- ✅ Быстрая установка
- ✅ Легкий вес проекта
