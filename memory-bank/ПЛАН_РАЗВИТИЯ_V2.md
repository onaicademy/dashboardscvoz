# ShowToday AI Analytics — Комплексный План Развития V2

> На основе анализа: [Roistat](https://roistat.com/rublog/skvoznaya-analitika./), [Воронка продаж Roistat](https://roistat.com/rublog/sales-funnel/), проекта AI-targetolog

---

## 🎯 Проблемы текущей версии

1. **Нет AI-функций** — просто статичные данные
2. **Тренды не обновляются** — только 2 неполные метрики
3. **Непонятно как работает каждый менеджер** — нет детализации по сотрудникам
4. **Не знаем откуда лиды** — нет воронки продаж
5. **Нет сквозной аналитики** — не видно путь клиента от первого касания до сделки
6. **Нет интеграций** — Bitrix24, WhatsApp не подключены

## 📊 Модуль 1: Воронка продаж (по модели Roistat)

### 1.1 Этапы воронки

```
┌─────────────────────────────────────────────────────────────┐
│  ТРАФИК (Источники)                                         │
│  ├── Instagram Ads                                          │
│  ├── Google Ads                                             │
│  ├── WhatsApp (органика)                                    │
│  ├── Referral (рекомендации)                                │
│  └── Direct (прямой заход)                                  │
├─────────────────────────────────────────────────────────────┤
│  ЛИДЫ (Первичные заявки)                       ▼ Конверсия  │
│  └── Новые обращения в WhatsApp/чат            100 → 80%    │
├─────────────────────────────────────────────────────────────┤
│  ПЕРВИЧНОЕ КАСАНИЕ                             ▼            │
│  └── Ответ менеджера < 5 мин                   80 → 65%     │
├─────────────────────────────────────────────────────────────┤
│  КВАЛИФИКАЦИЯ                                  ▼            │
│  └── Выявление потребности, бюджета            65 → 45%     │
├─────────────────────────────────────────────────────────────┤
│  ТЁПЛЫЙ СТАТУС                                 ▼            │
│  └── Клиент заинтересован, обсуждает детали    45 → 30%     │
├─────────────────────────────────────────────────────────────┤
│  СДЕЛКА                                        ▼            │
│  └── Оформлен заказ, получена оплата           30 → 25%     │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 Метрики по этапам

| Этап | Метрики |
|------|---------|
| Трафик | Визиты, Уникальные пользователи, Стоимость клика |
| Лиды | Кол-во заявок, CPL (Cost Per Lead), Конверсия в лид |
| Первичное касание | Время ответа, % отвеченных < 5 мин |
| Квалификация | Кол-во квалифицированных, Конверсия в тёплый |
| Тёплый | Кол-во тёплых, Средний чек, Время в статусе |
| Сделка | Кол-во сделок, Выручка, CAC, LTV, ROI |

## 🤖 Модуль 2: AI-функции

### 2.1 AI Анализ чатов (уже частично есть)

**Улучшения:**
- Автоматический скоринг лидов (HOT/WARM/COLD) по ключевым словам
- Определение намерения клиента
- Анализ тональности переписки
- Выявление возражений

**Из AI-targetolog (lead-scorer.ts):**
```typescript
// Скоринг по ключевым словам
HIGH_INTENT_KEYWORDS: { 'купить': 25, 'заказать': 25, 'цена': 20, 'срочно': 18 }
NEGATIVE_KEYWORDS: { 'дорого': -8, 'потом': -5, 'не интересует': -20 }

// Результат: HOT (61-100), WARM (31-60), COLD (0-30)
```

### 2.2 AI Бизнес-инсайты (из AI-targetolog)

**Сценарии автоматического обнаружения:**

| Сценарий | Индикаторы | Рекомендация AI |
|----------|------------|-----------------|
| `HIGH_ENGAGEMENT_LOW_SALES` | Много диалогов, мало сделок | "Проверьте скрипт закрытия — клиенты уходят на этапе оформления" |
| `BUDGET_DRAIN` | Затраты > 100K, конверсий 0 | "Остановите кампанию, проанализируйте аудиторию" |
| `SCALE_OPPORTUNITY` | ROAS > 3x, CPA < 50% цели | "Увеличьте бюджет на 50% — канал показывает отличные результаты" |
| `SLOW_RESPONSE` | Среднее время ответа > 30 мин | "Менеджер Айжан отвечает медленно — клиенты уходят к конкурентам" |
| `MANAGER_UNDERPERFORM` | Конверсия менеджера < 20% при норме 40% | "Менеджеру Бахытжан нужно обучение по работе с возражениями" |

### 2.3 AI Автоплан для менеджеров

interface ManagerDailyPlan {

## 🔗 Модуль 3: Интеграции

### 3.1 Bitrix24 CRM

**Синхронизация:**
- Сделки → ShowToday (статус, сумма, менеджер)
- Лиды → Воронка продаж
- UTM-метки → Атрибуция источника

**API endpoints (из AI-targetolog):**
```
/api/bitrix24/deals?domain={domain}
/api/bitrix/sync-leads
/api/bitrix24/webhooks
```

### 3.2 WhatsApp Business API

**Функции (из AI-targetolog):**
- Получение всех чатов и сообщений
- AI-скоринг каждого диалога
- Автоматическое определение статуса лида
- Уведомления о новых сообщениях

**Lead Scoring правила:**
```typescript
// Время ответа
under5min: +20 очков
under30min: +12 очков
under1hour: +5 очков

// Ключевые слова
"купить", "заказать": +25
"цена", "сколько": +20
"дорого": -8
"не интересует": -20

// Результат
HOT (61-100): Готов к сделке
WARM (31-60): Требует внимания
COLD (0-30): Нужно прогревать
```

### 3.3 Facebook/Instagram Ads

**Метрики:**
- Spend (затраты)
- Impressions, Clicks, CTR
- Leads, Conversions
- CPA, ROAS
