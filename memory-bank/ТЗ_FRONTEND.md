# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: Frontend MVP
## AI-Платформа аналитики чатов для ShowToday

---

## ОБЩЕЕ ОПИСАНИЕ

Разработать MVP веб-приложения для демонстрации платформы ИИ-аналитики переписок отдела продаж. Приложение должно выглядеть **премиально**, быть **полностью кликабельным** и демонстрировать все ключевые функции.

**Цель:** Презентация клиенту ShowToday для продажи проекта на 1,200,000 тг.

---

## ТЕХНИЧЕСКИЙ СТЕК

```
Framework:     Next.js 15 (App Router, latest)
Language:      TypeScript 5.x (strict mode)
Styling:       Tailwind CSS 4.0 (или 3.4 если 4.0 нестабилен)
UI Components: shadcn/ui (обязательно)
Icons:         Lucide React (НЕ Heroicons, НЕ стандартные)
               ИЛИ Phosphor Icons
               ИЛИ Tabler Icons
Charts:        Recharts или Tremor
Animations:    Framer Motion
Fonts:         Geist (рекомендуется для Next.js) / Inter
State:         Zustand (если нужен глобальный стейт)
```

### ВАЖНО ПО ИКОНКАМ:
**ЗАПРЕЩЕНО:** Heroicons, стандартные Tailwind иконки, Font Awesome
**РАЗРЕШЕНО:**
- `lucide-react` — современные, чистые (рекомендуется)
- `@phosphor-icons/react` — стильные, гибкие
- `@tabler/icons-react` — минималистичные

// Типы
interface Chat {
  id: string;
  clientName: string;
  clientPhone: string;
  agentEmail: string;
  agentName: string;
  score: number;
  amount: number;

}

interface ChatAnalysis {
  chatId: string;
  summary: string;
  goodPoints: string[];
