# РЕЗЮМЕ ПРОЕКТА: AI-Аналитика для ShowToday

## О КЛИЕНТЕ

**Компания:** ShowToday (8D)
**Сайт:** https://showtoday.kz/
**Сфера:** Организация развлекательных мероприятий (Event Management)
**Локация:** Алматы, Казахстан
**CRM:** Bitrix24

---

## БОЛИ КЛИЕНТА (выявленные проблемы)

### Отдел продаж:
1. **Скорость ответа** — менеджеры долго отвечают клиентам
2. **Неправильное закрытие сделок** — выбирают некорректные причины закрытия в CRM
3. **Слабая отработка возражений** — теряют клиентов на этапе общения
4. **Орфографические ошибки** — непрофессиональная коммуникация
5. **Отсутствие рекомендаций** — нет системы улучшения работы менеджеров

### Маркетинг:
6. **Не знают откуда заявки** — нет прозрачности по источникам лидов
7. **Таргет слепой** — крутят рекламу на охваты без аналитики
8. **Нет выводов по рекламе** — непонятно какие цели/офферы работают лучше
9. **Возможный слив бюджета** — маркетолог работает без метрик

---

## ЦЕЛЬ ПРОЕКТА

Создать **ИИ-платформу аналитики** для анализа текстовых переписок отдела продаж из Bitrix CRM с отдельным веб-приложением для просмотра результатов.

**Ключевой результат для клиента:**
- Прозрачная аналитика коммуникаций
- Понимание точек роста
- Контроль качества менеджеров
- Аналитика эффективности маркетинга

---

## ФУНКЦИОНАЛЬНОСТЬ ПЛАТФОРМЫ

### 1. Панель управления (Dashboard)
- Средняя оценка качества обслуживания
- Всего чатов за период
- Заказов оформлено
- Конверсия (%)
- Оценки по категориям (8 метрик)
- Частые ошибки менеджеров

### 2. Анализ чатов
- Список всех проанализированных диалогов
- Оценка каждого чата (1-10)
- Статус сделки (оформлен / не оформлен)
- Фильтры по менеджерам, датам, оценкам

### 3. Детальный анализ диалога
- Заключение ИИ по диалогу
- Что сделано хорошо (зеленый блок)
- Критические проблемы (красный блок)
- Упущенные возможности (желтый блок)
- Просмотр переписки с метками времени ответа
- Оценки по категориям для конкретного чата

### 4. Тренды
- Динамика оценок за период
- Графики по метрикам
- Сравнение менеджеров

### 5. Маркетинг-аналитика (наше преимущество)
- Источники заявок (откуда пришел лид)
- Эффективность рекламных каналов
- Конверсия по источникам
- ROI по каналам

### 6. Настройки
- Управление менеджерами
- Настройка метрик
- Интеграция с Bitrix

## 8 КЛЮЧЕВЫХ МЕТРИК АНАЛИЗА

| # | Метрика | Описание |
|---|---------|----------|
| 1 | Скорость ответа | Время реакции менеджера на сообщение клиента |
| 2 | Приветствие | Качество первого контакта |
| 3 | Знание продукта | Полнота информации о услугах и ценах |
| 4 | Техника продаж | Выявление потребностей, презентация, закрытие |
| 5 | Обработка заказа | Корректность оформления сделки |
| 6 | Сопровождение | Работа с клиентом после заявки |
| 7 | Решение проблем | Отработка возражений и жалоб |
| 8 | Коммуникация | Грамотность, вежливость, структура ответов |
